# Game UI Behavior Analysis & Bug Reporting

## Project Overview
This project focuses on analyzing the behavior, usability, and responsiveness of key game user interface (UI) elements. The objective is to understand how UI components impact player experience and to practice industry-style QA documentation and bug reporting.

This is a self-learning Quality Assurance exercise designed to simulate real-world game testing practices.

---

## Scope of Testing
The analysis covers the following UI components commonly found in modern video games:

- Main Menu Navigation  
- Heads-Up Display (HUD)  
- Mission Objective Prompts  
- Pause Menu and Settings  
- On-Screen Alerts and Notifications  
- Map and Waypoint System  

---

## Testing Approach
The project follows a structured QA approach:
- Observed expected vs actual UI behavior
- Evaluated clarity, responsiveness, and usability
- Identified minor usability issues
- Documented findings using standard QA reporting formats

---

## UI Behavior Observations
Each UI element was analyzed for:
- Visibility and placement
- Responsiveness to user actions
- Consistency during gameplay
- Impact on player experience

Most UI components functioned as expected, offering intuitive navigation and clear feedback.

---

## Bug Reporting Summary
Two low-severity usability issues were identified:
1. Mission objective text remaining visible briefly after completion
2. On-screen alerts overlapping HUD elements

These issues do not block gameplay but may affect clarity for new players. All bugs were documented with expected behavior, observed behavior, steps to reproduce, impact, and severity.
